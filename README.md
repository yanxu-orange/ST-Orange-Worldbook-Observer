# 世界书观测台 · 网络发行版

作者：砚梨

世界书观测台是基于 Tavern Helper 运行的 SillyTavern 世界书管理工具，支持手机、平板与 PC 三端响应式适配。

## 安装方式

- 推荐：下载并导入 `世界书观测台-网络同步版.json`。以后启动时会读取线上稳定版本。
- 回退：下载 `releases/v0.4.2/世界书观测台-v0.4.2.json`，作为不依赖网络的完整离线版。

网络同步版与离线版不要同时启用，以免注册重复按钮。

## 更新原则

- 只发布已经通过实机验收的稳定版本。
- 更新只在重新载入脚本或刷新 SillyTavern 后生效，不在编辑过程中热替换。
- 网络下载失败或 SHA-256 校验失败时停止执行，并提示改用离线版。

本仓库仅包含公开发行所需文件，不包含开发历史、测试材料、截图、私人样本或本机配置。
