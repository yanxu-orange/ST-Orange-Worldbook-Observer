# 世界书观测台 · 网络发行版

作者：砚梨

世界书观测台是基于 Tavern Helper 运行的 SillyTavern 世界书管理工具，支持手机、平板与 PC。

当前稳定版本：`v1.0.1`

## 安装

- 网络同步版：导入 [世界书观测台-网络同步版.json](世界书观测台-网络同步版.json)，以后重新载入脚本时读取线上稳定版本。
- 完整离线版：下载 [世界书观测台 v1.0.1](releases/v1.0.1/世界书观测台-v1.0.1.json)。

网络同步版与离线版不要同时启用，以免注册重复按钮。网络下载失败或 SHA-256 校验失败时会停止执行，并提示改用离线版。

## 功能

- 编辑世界书条目；
- 管理快捷组合与条目排列；
- 批量整理、查找替换；
- 跨书导入、复制与移动；
- 在统一保存前保留工作副本与撤销能力。
